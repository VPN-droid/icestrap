# Icestrap

A frosty alternative Roblox launcher for Windows: a clean settings app, mods, fast flags, Discord status and a launch window you can style.

## Download

Get **Icestrap-Setup.exe** from the [latest release](https://github.com/VPN-droid/icestrap/releases/latest) and run it. The setup lets you pick where to install and adds Desktop and Start Menu shortcuts.

Windows may say "Windows protected your PC" because the installer isn't code-signed. Click **More info → Run anyway**.

## Features

- Launches Roblox from links and keeps it up to date
- Mods: custom cursors, sounds and fonts (removing a mod restores the original)
- Fast flags editor with presets (FPS cap, graphics API, lighting and more)
- In-game settings applied before every launch
- Discord rich presence and game history with one-click rejoin
- Startup apps that open alongside Roblox
- Launch window styles, accent colours and light/dark themes
- Updates itself automatically

## Uninstalling

Use **Settings → Apps → Installed apps → Icestrap**. Roblox links go back to the launcher you used before.
